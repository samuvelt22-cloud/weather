About This Project

A simple Flask weather app built with Open-Meteo's free API.

What It Does

Weather Forecast is a beginner-friendly project that lets you search any city and get its current conditions and a multi-day outlook, pulled live from the Open-Meteo API. No API key, no sign-up, just search and see.

Key Features

Live Search

Look up current weather for any city by name.

Detailed Conditions

Temperature, feels-like, humidity, wind, sunrise & sunset.

5-Day Outlook

A quick glance at the days ahead, with min & max temps.

No API Key

Powered entirely by the free, open Open-Meteo API.
